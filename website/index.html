你说的话，
留在这台 Mac 上。

语音识别、翻译、文字识别，都在本机完成。
不用账号，不用 API key。

可选的 AI 润色默认关闭；打开后，文字只发到你自己配置的接口，不发声音，也不发截图。

开始之前

需要什么样的 Mac？

macOS 26 或更新的系统，Apple 芯片。

要联网、要账号吗？

不用账号。联网只用于下载模型和语言包，以及你主动打开的可选功能。

在哪些应用里能用？

能打字的地方基本都能用。少数接不上输入法的地方（比如一些终端），说完后会粘贴到光标处。

安装时被 macOS 拦住了怎么办？

安装包目前还没有经过 Apple 公证。按安装指南操作，不需要关闭系统的安全保护。
