# Saylane 安装和使用

## 安装

**已发布版本**：从 [GitHub Release](https://github.com/LiuTianjie/Saylane/releases/tag/v0.2.75) 下载 `Saylane-0.2.75.pkg`，发布页提供 `SHA256SUMS.txt` 可核对文件完整性。

**本机测试版本（0.3 起）**：`make pkg-local` 生成 `dist/Saylane-<版本>-<构建号>-local.pkg`。

**当前分发状态：包内的两个程序都有 Developer ID Application 签名，但 PKG 安装器本身未签名，也未完成 Apple 公证。从网上下载的安装包 macOS 可能阻止直接打开；不要关闭系统安全保护。在本机构建的安装包没有这个问题。**

按安装器走完，过程中可能要输入开机密码。0.3 起会装两个程序：

| 位置 | 是什么 |
|---|---|
| `/Library/Input Methods/Saylane.app` | 输入法：拼音打字、把文字写进输入框。不需要任何权限 |
| `/Applications/Saylane.app` | 主程序：语音、翻译、截屏翻译、设置。没有 Dock 图标；输入法用到它时会自动把它启动，开了辅助功能后还会在登录时启动（设置里可以关） |

从 0.2.x 升级会保留设置、已下载的模型和 Rime 用户词库。

### 升级时

- 从 0.2.x 升级：语音现在由新的主程序负责，系统把它当成一个新应用。第一次按住说话时会再问一次麦克风，点「允许」即可。
- 如果某个应用（例如微信）里选了 Saylane 却既不能拼音也不能说话、输入法菜单里也没有 Saylane 的子菜单，那是它在旧版本反复重启时被系统标记为“此输入法不可用”。这个标记只存在于那个应用的进程里，退出并重新打开该应用即可恢复。

## 装完之后

不用去系统设置添加输入法：安装结束时 Saylane 会自己加入输入法列表并切换过去。随后出现一页欢迎页：

1. 在试说框里**按住快捷键说一句**。第一次会弹出系统的麦克风询问，点「允许」，再按住说一次。
2. 下面三行是状态：**输入法**、**麦克风**、**辅助功能**。前两行应该都是「已开启」；哪一行不是，旁边有一个按钮，点它就地解决。
3. **辅助功能**是可选的：开了以后，快捷键在任何应用、任何输入法下都能用。这一项系统只允许你本人在系统设置里打开，所以按钮会带你过去。
4. 点「开始使用」。

语音识别（只有用 Apple 识别时需要）和屏幕录制（只有截屏翻译需要）在第一次用到时再问，也可以在设置的「权限管理」页里提前开。

## 使用

1. 点进备忘录、浏览器、聊天框，让光标在输入框里。
2. **单独按住**快捷键约 0.3 秒开始说话（默认右 Option，可在设置里改）。底部中间出现一条声波。
3. 文字直接出现在光标处。松开结束；Esc 取消。
4. 快捷键和别的键一起按（⌘C、⌥←、⌘ 点击）不会触发，也不会开麦。

快捷键在哪里有效：

| | 没开辅助功能 | 开了辅助功能 |
|---|---|---|
| 当前输入法是 Saylane，光标在输入框里 | 可以 | 可以 |
| 当前是别的输入法（ABC、豆包…） | 不可以 | 可以，写入方式为粘贴 |
| 光标不在输入框里 | 不可以 | 可以说，但没有地方接收；用「复制上一次听写」取回 |

写不进去的时候文字不会丢：会留在剪贴板并提示。输入法菜单里的「复制上一次听写」随时可以取回最近一次的结果。

## 出问题时

- 说话没反应：点菜单栏输入法图标 → Saylane 设置 → 权限管理，看哪一项没开。
- 主程序被退出了：打字不受影响；从输入法菜单打开「Saylane 设置…」会把它重新启动。
- 诊断记录在 `~/Library/Application Support/Saylane/Diagnostics/`（`ime.json` 是输入法，`app.json` 是主程序），只有阶段和状态，没有你说的或打的内容。

## 卸载

```bash
sudo bash scripts/uninstall.sh
```

会停用输入源、退出两个程序并删除它们，清掉系统隐私列表里给它的授权，并让系统的输入法菜单重新加载（旧图标不会残留）。设置、模型和词库保留在 `~/Library/Application Support/Saylane/`；连这些也不要的话：

```bash
sudo bash scripts/uninstall.sh --purge
```

安装新版本时不用先卸载：安装器会整体替换两个程序、结束旧进程、清掉旧版留下的授权和缓存的旧图标。
