# Saylane 安装和使用

## 安装

从 [GitHub Release](https://github.com/LiuTianjie/Saylane/releases/tag/v0.2.56) 下载 `Saylane-0.2.56.pkg`。发布页也提供 `SHA256SUMS.txt`，可核对文件完整性。v0.2.48 起使用 Saylane 品牌，安装器兼容旧版应用路径并保留设置和已下载模型。

**当前发布状态：包内应用有 Developer ID Application 签名，但 PKG 安装器本身未签名，也未完成 Apple 公证。macOS 可能阻止直接打开；不要关闭系统安全保护。**

打开 `dist/Saylane-<version>.pkg`（版本号随 `project.yml` / Info.plist 变化），按安装器走完。会装到：

`/Library/Input Methods/Saylane.app`

和豆包输入法同一个位置。安装过程可能要输入开机密码。

## 启用输入法

1. 打开 **系统设置 → 键盘 → 输入法**（安装结束会尽量自动打开）
2. 点 **添加**，找到 **Saylane**，加上
3. 菜单栏输入法图标切到 **Saylane**（和切到豆包一样）

如果安装脚本已经自动启用，菜单栏里直接就能看到 Saylane。

## 使用

1. 点进备忘录、浏览器、聊天框，让光标在输入框里
2. 确认当前输入法是 Saylane，或已在设置里允许「输入监控」
3. 按住快捷键说话（默认右 Option，可在菜单栏设置里改）
4. 英文会直接出现在输入框里；底部中间只有一条声波
5. 松开结束；Esc 取消。说完后会保持 Saylane，方便继续拼音

第一次会要麦克风和语音识别权限。若希望在其它输入法下也能按住说话，再允许输入监控。不使用剪贴板。
